# Machine Learning Projects

A collection of machine learning coursework and applied projects
covering data preprocessing, exploratory data analysis, supervised
learning, model evaluation, and predictive modeling.

## Projects

### Machine Failure Prediction
Applied machine learning to predict machine failures from operational
and sensor data.

**Methods:** Data preprocessing, feature engineering, classification,
model comparison, and performance evaluation.

### Coursework

A collection of machine learning homework assignments covering
fundamental concepts and algorithms.
